# آینده شاپ | Django Online Shop

پروژه آموزشی فروشگاه اینترنتی با Django، PostgreSQL، Bootstrap 5 و قالب‌های Django.

## امکانات
- صفحه اصلی و دسته‌بندی محصولات
- فهرست و جزئیات محصول
- جستجو، مرتب‌سازی بر اساس قیمت قابل پرداخت و صفحه‌بندی
- نمایش قیمت‌ها با جداکننده سه‌رقمی
- تعریف درصد تخفیف برای هر محصول و نمایش قیمت اصلی، قیمت نهایی و میزان صرفه‌جویی
- مدیریت محصولات و دسته‌بندی‌ها در Django Admin
- مرتب‌سازی محصولات و فیلتر بر اساس بازه قیمت نهایی، تخفیف‌دار بودن و موجودی
- غیرفعال‌کردن دسته‌بندی بدون حذف محصولات؛ محصولات تا زمان فعال‌سازی مجدد دسته‌بندی از بخش عمومی فروشگاه مخفی می‌مانند
- حذف دسته‌بندی همراه با حذف محصولات وابسته؛ سوابق سفارش‌های قبلی با نام و قیمت ثبت‌شده حفظ می‌شوند
- ثبت‌نام، ورود و خروج کاربران
- سبد خرید مبتنی بر Session با محاسبه قیمت پس از تخفیف
- ثبت سفارش با ثبت قیمت نهاییِ زمان خرید و مشاهده سفارش‌های کاربر
- کاهش موجودی هنگام ثبت سفارش با تراکنش دیتابیس

## پیش‌نیازها
- Python 3.11 یا بالاتر
- PostgreSQL
- pip

## راه‌اندازی در ویندوز

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

در Linux/macOS:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## تنظیم PostgreSQL
1. در PostgreSQL یک دیتابیس به نام `ayandeh_shop` و یک کاربر بسازید.
2. فایل `.env.example` را به `.env` تغییر نام دهید.
3. مقادیر DB_NAME، DB_USER، DB_PASSWORD، DB_HOST و DB_PORT را تنظیم کنید.
4. SECRET_KEY را با یک مقدار امن جایگزین کنید.

نمونه ساخت دیتابیس در psql:

```sql
CREATE DATABASE ayandeh_shop;
CREATE USER shop_user WITH PASSWORD 'strong-password';
GRANT ALL PRIVILEGES ON DATABASE ayandeh_shop TO shop_user;
ALTER DATABASE ayandeh_shop OWNER TO shop_user;
```

## اجرای پروژه

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

سپس:
- فروشگاه: http://127.0.0.1:8000/
- پنل مدیریت: http://127.0.0.1:8000/admin/

> فایل‌های migration طوری تنظیم شده‌اند که ابتدا ساختار نسخه اولیه را ثبت و سپس فیلد تخفیف و روابط حذف را ارتقا دهند. اگر دیتابیس قدیمی را پیش‌تر با جدول‌های همین پروژه ساخته‌اید اما migrationهای اولیه را در آن ثبت نکرده‌اید، ابتدا نسخه پشتیبان بگیرید و سپس از `python manage.py migrate --fake-initial` استفاده کنید تا ساختار اولیه ثبت و migrationهای ارتقا اجرا شوند. اگر جدول‌ها وجود ندارند، اجرای معمول `python manage.py migrate` کافی است.

## مدیریت تخفیف
در پنل مدیریت، وارد بخش محصولات شوید و مقدار «درصد تخفیف» را تعیین کنید. مقدار صفر یعنی بدون تخفیف؛ مقدار بین ۱ تا ۱۰۰ درصد تخفیف اعمال می‌کند. قیمت قابل پرداخت در کارت محصول، صفحه جزئیات، سبد خرید و سفارش محاسبه می‌شود.

## نکات فنی
- قیمت‌ها در پایگاه داده به تومان و به‌صورت عدد صحیح ذخیره می‌شوند.
- جداکننده سه‌رقمی فقط برای نمایش اعمال می‌شود و مقدار عددی قیمت در پایگاه داده تغییر نمی‌کند.
- غیرفعال‌کردن دسته‌بندی، مقدار فعال‌بودن محصولات را تغییر نمی‌دهد؛ نمایش عمومی به فعال‌بودن هم‌زمان محصول و دسته‌بندی وابسته است.
- حذف دسته‌بندی محصولات آن را حذف می‌کند. برای حفظ تاریخچه سفارش، ارتباط محصول از ردیف‌های سفارش قبلی خالی می‌شود، اما نام و قیمت ذخیره‌شده در زمان خرید باقی می‌ماند.
- سبد خرید در Session نگهداری می‌شود.
- قیمت و نام محصول هنگام ثبت سفارش در OrderItem کپی می‌شود تا تغییرات بعدی محصول یا حذف آن، تاریخچه سفارش را عوض نکند.
- برای جلوگیری از فروش بیش از موجودی، ثبت سفارش در `transaction.atomic` انجام می‌شود و ردیف محصول قفل می‌شود.
- در محیط Production باید DEBUG خاموش، SECRET_KEY امن، HTTPS و تنظیمات Static/Media مناسب فعال شوند.

## ساختار پروژه

```text
config/      تنظیمات و URLهای اصلی

products/    دسته‌بندی، محصولات، تخفیف و قالب‌بندی قیمت
accounts/    ثبت‌نام و ورود
cart/        سبد خرید Session-based
orders/      ثبت و مشاهده سفارش‌ها
templates/   قالب‌های HTML
static/      فایل‌های CSS و JavaScript
media/       تصاویر آپلودشده
```
